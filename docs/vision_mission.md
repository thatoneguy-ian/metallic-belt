# Vision and Mission

## Vision
To break down the barriers between tabletop gaming platforms, providing players and game masters with a seamless, immersive, and zero-overhead virtual tabletop experience.

## Mission
To deliver a reliable, lightweight, and high-performance integration that embeds the industry-standard D&D Beyond character sheet directly into Foundry VTT. This integration will:
1. **Preserve full support** for advanced combat automation systems (such as `midi-qol` and `chris-premades`).
2. **Eliminate dual-maintenance** by keeping D&D Beyond as the source of truth for character building while automating state synchronization bidirectionally.
3. **Minimize player friction** by letting them use the familiar D&D Beyond UI inside the virtual tabletop without needing to manage separate browser tabs or manually sync sheets.
